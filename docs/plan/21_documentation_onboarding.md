## Struktur Dokumentasi (/docs)
- Sidebar tingkat pertama: "Developer", "Klien", "Referensi".
- Maksimal 15 halaman awal:
  1. Developer / Getting Started
  2. Developer / Arsitektur Proyek Astro
  3. Developer / Panduan Deploy Cloudflare
  4. Developer / Integrasi Supabase & RBAC
  5. Developer / Pipeline CI-CD
  6. Developer / Standar Keamanan
  7. Developer / Testing & QA
  8. Klien / Onboarding Portal
  9. Klien / Mengelola Proyek & Deploy
 10. Klien / Paket & Upgrade
 11. Klien / Pembayaran & Faktur
 12. Klien / Dukungan & SLA
 13. Klien / Dokumentasi & Tutorial Video
 14. Referensi / Changelog
 15. Referensi / FAQ Umum

## Format Halaman
- Bahasa Indonesia formal, gunakan kalimat aktif jelas.
- Sertakan ringkasan di awal, langkah terurut, dan checklist bila relevan.
- Halaman video menyertakan transkrip teks.

## Konten Khusus
- Template proposal/quotation: file markdown `/docs/templates/proposal.md` dengan bagian Latar Belakang, Lingkup, Jadwal, Investasi, Syarat Pembayaran.
- Template invoice: `/docs/templates/invoice.md` mencantumkan detail perusahaan, nomor invoice, deskripsi layanan, PPN, total.
- Changelog gunakan format tanggal ISO (`## 2024-05-01`).
- Peta rilis: tabel milestone per kuartal, tautan ke roadmap (Notion).

## Onboarding Klien
- Kirim welcome email dengan link ke `/docs/klien/onboarding-portal` + video tutorial.
- Sertakan checklist pre-launch (domain, konten, aset brand).
- Jadwalkan sesi training 60 menit via Google Meet; rekaman diunggah ke tutorial page.
