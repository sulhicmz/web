# AstroPro Digital - Brand Guidelines

Comprehensive brand identity system untuk AstroPro Digital sebagai platform manajemen proyek dan konsultasi digital terpercaya.

## 🎨 Brand Overview

"Empowering businesses through innovative digital project management and consultation services that deliver exceptional results and lasting partnerships."

"To be the leading digital project management platform in Indonesia, known for reliability, innovation, and client-centric solutions."

- **Reliability** - Consistent, dependable service delivery
- **Innovation** - Cutting-edge technology and creative solutions
- **Client-Centric** - Putting client success at the forefront
- **Professionalism** - Expert knowledge and ethical practices
- **Growth** - Continuous improvement and learning

### Typography System

#### Primary Font Family
**Atkinson Hyperlegible**
- **Reason**: Excellent readability, accessibility-focused
- **Styles**: Regular (400), Bold (700)
- **Usage**: Body text, headings, UI elements

#### Font Scale (Fluid Typography)
```css
/* Headings */

--font-size-h3: clamp(1.5rem, 2vw, 1.875rem);     /* 24-30px */
--font-size-h4: clamp(1.25rem, 1.5vw, 1.5rem);    /* 20-24px */

/* Body Text */
--font-size-body-lg: clamp(1.125rem, 1.2vw, 1.25rem);  /* 18-20px */
```

#### Font Weights
- **Light (300)**: Secondary text, captions

- **Medium (500)**: Subheadings, important info
- **Semibold (600)**: Small headings, emphasis
- **Bold (700)**: Main headings, CTA buttons

### Logo Design

#### Logo Concept
**Simbol**: Abstract "A" dengan elemen orbital yang melambangkan:
- **Precision** - Lingkaran orbital menunjukkan akurasi
- **Technology** - Elemen modern dan futuristic
- **Growth** - Gerakan maju dan perkembangan

#### Logo Variations
1. **Primary Logo** - Full color dengan tagline
2. **Secondary Logo** - Monochrome untuk flexibilitas
3. **Icon Only** - Untuk favicon dan app icons
4. **Wordmark** - Text-only untuk readability

#### Logo Usage Rules
- **Minimum size**: 32px untuk digital, 1cm untuk print
- **Clear space**: 25% dari logo height di semua sisi
- **Background**: Gunakan pada background kontras
- **Don't**: Jangan stretch, rotate, atau modify logo

## 📐 Design Principles

### 1. Modern & Clean
- **Whitespace**: Generous spacing untuk readability
- **Hierarchy**: Clear visual hierarchy dengan typography
- **Simplicity**: Clean layouts tanpa clutter

### 2. Professional & Trustworthy
- **Consistency**: Uniform styling di semua platform
- **Quality**: High-quality visuals dan typography
- **Reliability**: Stable dan predictable design patterns

### 3. Accessible & Inclusive
- **WCAG AA**: Minimum contrast ratio 4.5:1
- **Readability**: Font size minimal 16px untuk body text
- **Color Independence**: Design works tanpa color alone
- **Motion**: Respects prefers-reduced-motion

### 4. Mobile-First & Responsive
- **Touch Targets**: Minimum 44px untuk interactive elements
- **Fluid Typography**: Responsive text sizing
- **Progressive Enhancement**: Core functionality tanpa JavaScript

## ♿ Accessibility Guidelines

### Color Contrast
- **Primary text**: Minimum 4.5:1 contrast ratio
- **Secondary text**: Minimum 4.5:1 contrast ratio
- **Interactive elements**: Minimum 3:1 contrast ratio
- **Focus indicators**: High contrast dan visible

### Typography
- **Minimum font size**: 16px untuk body text
- **Line height**: Minimum 1.5 untuk readability
- **Letter spacing**: Optimized untuk setiap font size
- **Font loading**: font-display: swap untuk performance

### Interaction
- **Touch targets**: Minimum 44px x 44px
- **Focus indicators**: Visible dan high contrast
- **Keyboard navigation**: Full keyboard accessibility
- **Screen readers**: Proper ARIA labels dan descriptions

## 🚀 Implementation Guidelines

### Development Workflow
1. **Design**: Create dengan design tokens
2. **Develop**: Implement dengan component system
3. **Test**: Validate accessibility dan responsiveness
4. **Document**: Update component documentation
5. **Review**: Design dan development review

### Code Standards
```css
/* Use design tokens */
.my-component {
  padding: var(--space-4);
  background: var(--color-surface-elevated);
  border-radius: var(--radius-lg);
  color: var(--color-text-primary);
}

/* Responsive design */
@media (max-width: 768px) {
  .my-component {
    padding: var(--space-3);
  }
}

/* Accessibility */
@media (prefers-reduced-motion: reduce) {
  .my-component {
    transition: none;
  }
}
```
